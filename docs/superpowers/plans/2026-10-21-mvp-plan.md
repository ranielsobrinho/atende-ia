# atende-ia — Plano MVP (aprovado em 21/10/2026)

> **Produto:** Recepção de voz IA pt-BR para clínicas odontológicas e de fisioterapia.
> Atende o telefone 24/7 (recebe ligações encaminhadas), segue uma **árvore de diálogo
> configurável por clínica**, envia áudio de confirmação no WhatsApp após a ligação.
> Diferencial: motor próprio de árvore de diálogo (não plataforma gerenciada).

## 2. Arquitetura

```
Paciente ──ligação──► Twilio (número BR, Media Streams WS)
                      │ áudio μ-law
                      ▼
      RUNTIME Python — Pipecat (transporte Twilio)
        STT (ElevenLabs Realtime) → MOTOR FSM (nosso interpretador)
        → TTS (ElevenLabs flash v2.5 pt-BR) + LLM barato (gpt-4o-mini)
        − decide aresta e extrai slots; fala sai do grafo
                      │
      API Node.js/Fastify (hexagonal, template todo-hexagonal)
        tenants · árvores versionadas · agenda Google
        WhatsApp Cloud API (áudio) · billing · webhooks
                      │
      Postgres 16 (tenants, call_tree_versions, calls, transcripts)
```

- Runtime lê árvore do Postgres/direto (semana 1: arquivo local; depois gRPC ou SQL).
- Editor de árvore: React Flow (semana 4).
- WhatsApp post-call: TTS → OGG/Opus (ffmpeg, já instalado) → Cloud API `ptt:true` (janela 24h).
- Billing: Asaas/Pagar.me — Pix Automático + cartão.
- LGPD: aviso de gravação no início da chamada, minimização de dados, transcrições cifradas.

## 3. DSL da árvore (autoritativo — API e runtime compartilham)

```jsonc
{
  "version": "1",
  "entry": "boas_vindas",
  "nodes": {
    "boas_vindas": {
      "speech": "Olá, {clinica}! Como posso ajudar?",
      "instructions": "opcional, dica pro LLM",
      "extract": {
        "motivo": ["agendar", "remarcar", "urgente", "duvida", "outro"],
      },
      "edges": [
        { "when": "motivo == 'urgente'", "goto": "triagem_urgente" },
        { "when": "fallback", "goto": "duvida_livre" },
      ],
      "action": "google_calendar.create", // opcional (tool)
      "postCall": { "whatsapp_audio": "confirmacao_agendamento" },
      "then": "encerrar",
    },
  },
}
```

Regras: `edge.goto` aceita nó ou literais `transferir_humano` / `encerrar`;
toda árvore deve ter caminho de escape (fallback → humano);
`extract` aceita lista de valores fechados ou `"FREE_TEXT"` (slot = fala inteira);
retries: sem match e retry_count >= 2 → `transferir_humano`.
